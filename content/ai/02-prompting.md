## 为什么同一句话，别人用得好？

大模型像一个「读过万卷书但完全不了解你处境」的聪明实习生。你说「写个文案」，它只能随机发挥；你说清楚背景、受众、风格和格式，它立刻靠谱。提示词工程就是把「隐含需求」显式化的手艺。

## 四个立刻可用的技巧

### 1. 设定角色与背景

```text
你是一位面向初中生的物理老师。请用生活里的例子解释什么是惯性，
不超过 200 字，最后留一道小练习题。
```

### 2. Few-shot：给例子比讲规则有效

```text
请按示例风格给下面的城市写一句话宣传语。
示例：
北京 → 千年古都，一步一故事。
成都 → 一座来了就不想走的城市。
现在请写：杭州 →
```

### 3. 要求结构化输出

```text
分析这句话的情感倾向，以 JSON 输出：
{"sentiment": "正面/负面/中性", "confidence": 0到1, "reason": "一句话理由"}
```

### 4. 复杂任务用思维链

```text
请一步步推理：小明有 3 盒弹珠，每盒 12 颗，送给朋友 15 颗，
还剩多少颗？请先写出每一步，再给最终答案。
```

## 迭代是常态

专业使用者没有「一发入魂」的秘诀：先写一版 → 看输出哪里不对 → 补一条明确约束（例如「不要用感叹号」「只输出 JSON 本身」）→ 再跑。三轮迭代通常能解决八成问题。

> 💡 **检验标准**：把你的提示词发给一个没读过对话背景的人，他能否准确完成任务？能，模型也可以。
